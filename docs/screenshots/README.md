# Capturas de demostración

Interfaz real de DynIsland renderizada en Chromium mediante el frontend del proyecto, con un puente IPC de demostración en memoria. No son mockups ni pruebas de la integración nativa Windows/Linux. La música, portada, archivos, tareas, batería, WiFi, fecha y progreso son ficticios. No se leen ni escriben datos del usuario.

Regeneración: instala Playwright y Chromium fuera del proyecto, y ejecuta `node tools/capture-screenshots.mjs /ruta/a/playwright/index.mjs`.
